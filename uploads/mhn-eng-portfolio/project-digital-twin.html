2 kg Acrobatic UAV Digital Twin

A full digital-twin ecosystem built around a 6-DOF flight simulation — live telemetry, a sub-2ms low-fidelity physics suite, and a real-vs-simulated comparison dashboard, with no training data required.

Aircraft
2 kg acrobatic UAV
Telemetry
MAVLink @ 100 Hz
Physics cycle
< 2 ms, no training data
Stack
MATLAB · Python · Three.js

Starting point

The project began as a 6-DOF flight dynamics simulation built in MATLAB/Simulink — the standard tool for early flight-control and handling-qualities work. The goal was to extend that offline model into something that runs alongside a real aircraft in the field, comparing live behaviour against the simulated prediction in real time.

Building the twin

A Python service receives MAVLink telemetry from a Pixhawk flight controller at 100 Hz and stores it in MongoDB and InfluxDB for both structured querying and time-series analysis. A comparison engine runs the real telemetry stream against the simulated 6-DOF model concurrently, and an HTML dashboard — built with Three.js for 3D attitude visualization and Chart.js for time-series plots — renders both in real time.

The physics layer deliberately avoids a data-hungry ML surrogate. Instead it's a low-fidelity analytical suite — thin airfoil theory and lifting-line theory for aerodynamic loads, beam theory for structural deflection, Von Mises stress evaluation, and Miner's rule for fatigue accumulation — chosen so the whole physics stack executes in under 2 ms per cycle with zero training data, making it usable from the very first flight rather than after a data-collection campaign.
